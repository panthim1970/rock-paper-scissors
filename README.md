Το παιχνίδι "Πέτρα-Ψαλίδι-Χαρτί" στην Python είναι ένα απλό πρόγραμμα που χρησιμοποιεί την τυχαία επιλογή (συνάρτηση
randint) για να διαλέξει ο υπολογιστής (Πέτρα, Ψαλίδι ή Χαρτί) και συγκρίνει την επιλογή του με αυτή του παίκτη, βασιζόμενο σε κανόνες (Πέτρα σπάει Ψαλίδι, Ψαλίδι κόβει Χαρτί, Χαρτί καλύπτει Πέτρα) για να βρει τον νικητή. 
Πώς λειτουργεί (Βασική Περιγραφή):

    Επιλογές: Ορίζονται οι τρεις επιλογές (Πέτρα, Ψαλίδι, Χαρτί) συνήθως ως λίστα ή αριθμοί (π.χ., 0, 1, 2).
    Τυχαία Επιλογή Υπολογιστή: Χρησιμοποιείται η random.randint(0, 2) (ή παρόμοια συνάρτηση) για να επιλέξει ο υπολογιστής έναν από τους τρεις αριθμούς τυχαία.
    Επιλογή Παίκτη: Ο παίκτης εισάγει την επιλογή του (π.χ., πληκτρολογώντας "πέτρα", "ψαλίδι", "χαρτί" ή αριθμό).
    Σύγκριση (Λογική): Το πρόγραμμα συγκρίνει τις δύο επιλογές.
        Αν είναι ίδιες, ισοπαλία.
        Αν ο υπολογιστής διαλέξει Πέτρα (0) και ο παίκτης Ψαλίδι (1), νικά ο υπολογιστής.
        Αν ο υπολογιστής διαλέξει Ψαλίδι (1) και ο παίκτης Χαρτί (2), νικά ο υπολογιστής, κ.ο.κ.
    Αποτελέσματα: Εμφανίζεται ποιος κέρδισε ή αν είναι ισοπαλία. 

Βασικά Στοιχεία Python:

    import random: Για να χρησιμοποιήσουμε τυχαίες επιλογές.
    random.randint(a, b): Επιστρέφει έναν τυχαίο ακέραιο ανάμεσα στο a και το b (συμπεριλαμβανομένων).
    input(): Για την εισαγωγή δεδομένων από τον παίκτη.
    if/elif/else: Για τη λογική σύγκρισης και τον έλεγχο των κανόνων
